# 10 — Ball height (z) and the goalkeeper in flight

Builds the z-trajectory and goalkeeper-movement curves from the window data
(ball z per frame; defending GK identified from the roster).

**Headline:** the early signal is horizontal — z adds +0.0009 (nothing) in the first
flight tenth and only +0.012 at arrival; the keeper is a minor character in flight
(≤0.60 alone; visible in only 50.5% of instants — broadcast limitation, noted).

**Run:** `python run09.py --run <id>`.
