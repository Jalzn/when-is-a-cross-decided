# 06 — The receiver's curve (WHOM does the arrival belong to)

Assigns the primary receiver (nearest attacker to the ball at arrival, crosser
excluded) and primary defender per cross, then aggregates the arrival block's
out-of-fold score by role — receiver, defender, crosser (control) — and measures
temporal split-half stability.

**Headline:** receiver 0.380 and defender 0.356 vs crosser 0.216 — the aerial contest
belongs more to whoever disputes the ball; still the noisiest link in the chain
(strike situation is 0.53–0.74).

**Run:** `python run05.py --run <id>`.
