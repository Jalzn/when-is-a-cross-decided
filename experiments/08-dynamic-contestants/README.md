# 08 — Dynamic contestants (leak-free) and receiver emergence

(crosser excluded) — no future information. Rebuilds the separation curve, measures
identity switches, and asks when the eventual receiver becomes identifiable.

the first flight tenth while the contest is still undifferentiated (gap 0.29 m) and
the receiver unrecognizable (P = 5–18% at 10–25% of flight); identity crystallizes
(28% → 100%) and separation diverges by outcome (0.8 → 2.0 m) only in the last
third. Clean pre-touch values confirm front 07's leak (0.52 vs 0.75).
