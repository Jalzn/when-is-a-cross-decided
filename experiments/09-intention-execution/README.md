# 09 — Intention vs execution in the early ball signal

Decomposes the first-tenth signal: (A) realized destination (where the ball ended),
(B) early execution (trajectory features at f010/f020), (C) both, (D) execution
residualized on destination (OLS, label-free).

**Headline:** destination 0.737 ≈ execution 0.729 (statistically indistinguishable),
complementary together (0.777): neither aim nor strike dominates — and neither is an
individual trait (front 03).
